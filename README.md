# Tagmar 1ª - Tema Pergaminho (módulo para Foundry VTT)

Módulo opcional de visual para o sistema **Tagmar 1ª Edição (não oficial)**. Ele só altera a aparência; não muda nenhuma regra.

## O que ele faz

- **Mensagens de rolagem no chat** em cartões de pergaminho, com faixa carmim.
- **Janelas de pergunta** (ataque, habilidade, dano, Energia Heróica) em estilo pergaminho.
- **Enfeites da ficha**: florões nos títulos das seções, moldura dupla no cabeçalho e caixas ao redor das energias e da armadura.

O tema base da ficha (cores, fontes, papel) já vem dentro do sistema, a partir da versão 0.4.0. Em **Configurações → Configurar opções → Sistema → Tema da ficha** você escolhe entre **Pergaminho medieval** e **Simples**. Os enfeites da ficha só aparecem com o tema Pergaminho.

## Instalação

1. Instale o sistema [tagmar1e-foundry](https://github.com/claezius/tagmar1e-foundry) na versão 0.4.0 ou superior.
2. No Foundry, abra **Add-on Modules → Install Module** e cole em **Manifest URL**:

   `https://github.com/claezius/tagmar1e-pergaminho/releases/latest/download/module.json`

3. Dentro do mundo, ative o módulo em **Manage Modules**.

## Compatibilidade

Foundry v13 e v14, com o sistema Tagmar 1ª Edição (não oficial) 0.4.0 ou mais novo. Nenhuma fonte externa é carregada: o módulo usa só fontes comuns com serifa.
